# تحديث فيديو خدمات البوابة (أفقي 1920×1080)

يُبنى الفيديو الجديد من الفيديو الأول (120 ث) بإضافة ثلاثة مشاهد بنفس التصميم:
الاستخدام الفعلي بأرقام محدَّثة، و«08 الجديد في البوابة»، و«09 إنجازات المدرسة».

| الملف | المحتوى |
|---|---|
| `stats.sql` | أرقام الاستخدام الفعلي (تُشغَّل في Supabase ← SQL Editor، قراءة فقط) |
| `VOICEOVER-update.txt` | نص التعليق الصوتي المشكول للمشاهد الجديدة |
| `scenes.html` | المشاهد الثلاثة؛ الحركة دالة في الزمن `render(t)` |
| `snap.mjs` | لقطات مراجعة عند أزمنة محددة |
| `rec.mjs` | تصدير مشهد إطارًا بإطار |
| `build.py` | تصدير المشاهد بأطوال الصوت ثم تجميع الفيديو النهائي |

الملفات التي لا تُرفع للمستودع: `in/src.mov` (الفيديو الأول)، و`assets/` (صور الإنجازات ولقطات
النماذج)، و`vo/` (التسجيلات)، و`out/`.

```
python3 build.py          # الناتج out/makkahsec-portal-2026.mp4
```
