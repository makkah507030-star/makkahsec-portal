# دليل المعلم: ملف المعلم الرقمي

`teacher-dfile-guide.pdf` دليل استخدام المعلم للملف الرقمي بالشاشات، بهوية الملف نفسه (A4).

## الملفات
- `guide.html`: نص الدليل وتصميمه. كل صفحة `<section class="page">`.
- `shots/`: صور الشاشات، يلتقطها `shots.mjs` من الكود الحالي.
- `harness/`: بيئة تعرض شاشات الملف ببيانات تجريبية دون قاعدة بيانات
  (`sb-stub.js` بيانات وهمية، و`sample.pdf` شاهد تجريبي).
- `build.mjs`: يلتقط الشاشات ثم يطبع الدليل PDF.

## عند تعديل الملف الرقمي
1. عدّل نص الصفحة المعنية في `guide.html` (أو أضف صفحة).
2. إن ظهرت شاشة جديدة: أضفها في `shots.mjs` واستخدم اسمها في `guide.html`.
3. أضف سطرًا في «سجل التعديلات» آخر الدليل، وارفع رقم الإصدار وتاريخه في الغلاف.
4. من جذر المستودع: `node docs/teacher-digital-file/guide/build.mjs`
   (أو `--no-shots` لإعادة الطباعة بالصور الحالية).

الملفات هنا لا تُنشر مع الموقع (`docs/` مستثناة من النشر في `netlify.toml`).
