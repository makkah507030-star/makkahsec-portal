# دليل الدعم الفني: تثبيت ملف المعمل وقفل أجهزة الطلاب

الهدف: عند دخول الطالب إلى حسابه في جهاز المعمل يفتح ملف المعمل تلقائيًا بملء الشاشة، ولا
يصل إلى سطح المكتب. الخروج بـ Ctrl+Alt+Del ثم تسجيل الخروج، ويدخل المعلم أو المسؤول بكلمة
مرور حسابه.

> **جرّب على جهاز واحد أولًا**، ثم عمّم على بقية الأجهزة بعد التأكد.

---

## ١. تنزيل الملف الدائم (مرة واحدة)

1. البوابة ← المعامل والمختبرات ← معمل الحاسب الآلي ← الدروس ← «حصص الطلاب».
2. في «الملف الدائم لأجهزة المعمل» اضغط «إصدار الملف»، واكتب **رمز المعلم** (4 إلى 8 أرقام)
   وأكّده. يُنزَّل ملف اسمه `lab.html`.
3. احتفظ برمز المعلم؛ يُطلب على الأجهزة لتبديل الطالب.

## ٢. نسخ الملف إلى كل جهاز

1. أنشئ المجلد `C:\MakkahLab` وانسخ إليه `lab.html` بالاسم نفسه.
2. تأكد أن حساب الطالب يستطيع **قراءة** المجلد (الإعداد الافتراضي يكفي عادة).

رابط التشغيل لكل جهاز يحمل رقمه في آخره (مثال للجهاز 5):

```
file:///C:/MakkahLab/lab.html#seat=5
```

غيّر الرقم بعد `seat=` حسب الرقم المكتوب على خلفية سطح المكتب لكل جهاز (1 إلى 24).

## ٣. القفل: الطريقة الأولى (الموصى بها) — Kiosk في Windows

تتطلب Windows 10 أو 11 بإصدار Pro أو Education أو Enterprise (لا تعمل في Home).

1. بحساب المسؤول: Settings ← Accounts ← Other users (أو Family & other users).
2. في قسم **Kiosk** اضغط **Get started** (أو Set up a kiosk).
3. اختر حساب الطالب المحدود (أو أنشئ حسابًا جديدًا للمعمل).
4. اختر التطبيق **Microsoft Edge**، ثم **As a digital sign or interactive display**.
5. في العنوان (URL) اكتب رابط الجهاز من الخطوة ٢، مثل `file:///C:/MakkahLab/lab.html#seat=5`.
6. في مدة الخمول قبل إعادة التشغيل (Idle time) اختر **أطول مدة متاحة** أو «Never»؛ فإعادة
   التشغيل أثناء الحصة تُفقد الطالب تقدّمه في الدرس.
7. أعد تشغيل الجهاز وادخل بحساب الطالب: يجب أن يظهر ملف المعمل بملء الشاشة دون شريط مهام.

الخروج: **Ctrl+Alt+Del** ← Sign out، ثم الدخول بحساب المعلم أو المسؤول.

**إذا لم يقبل Edge الرابط المحلي** (`file:///`) أو لم يظهر الملف، فاستخدم الطريقة الثانية
وأبلغ مطوّر البوابة.

## ٤. القفل: الطريقة الثانية (بديلة، أضعف)

تُستخدم إن لم تتوفر الطريقة الأولى. تفتح الملف تلقائيًا بملء الشاشة، لكنها لا تمنع كل
الاختصارات منعًا تامًا.

1. سجّل الدخول بحساب الطالب، واضغط Win+R واكتب `shell:startup` ثم Enter.
2. أنشئ في المجلد الذي يُفتح اختصارًا (New ← Shortcut) هدفه (للجهاز 5):

   ```
   "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk "file:///C:/MakkahLab/lab.html#seat=5" --edge-kiosk-type=fullscreen --no-first-run
   ```

3. بحساب المسؤول، قيّد حساب الطالب من Local Group Policy (`gpedit.msc`) ←
   User Configuration ← Administrative Templates:
   - System ← Ctrl+Alt+Del Options ← **Remove Task Manager**: Enabled
   - Windows Components ← File Explorer ← **Turn off Windows Key hotkeys**: Enabled
   - Start Menu and Taskbar ← **Remove Run menu from Start Menu**: Enabled
   - System ← **Prevent access to the command prompt**: Enabled

   (لتطبيق السياسة على حساب الطالب وحده، استخدم ملف سياسة للمستخدمين غير المسؤولين عبر
   `mmc` ← Group Policy Object Editor ← Browse ← Users ← Non-Administrators.)

## ٥. في الحصة

- يفتح المعلم في البوابة «فتح حصة برمز»، ويختار الفصل والدرس، فيظهر **رمز الحصة** (5 أرقام)،
  ويعرض الدرس على السبورة والرمز في أعلاه.
- يكتب الطلاب الرمز في ملف المعمل، ويختارون أسماءهم، ويؤدّون الدرس.
- في النهاية يمسح المعلم رمز الدرجة على كل شاشة من «مسح الدرجات».
- للفصل التالي: «حصة جديدة» أسفل الشاشة، ثم رمز الحصة الجديد.
- **تاريخ الجهاز وساعته** يجب أن يكونا صحيحين؛ فرمز الحصة يعمل في يومه فقط.

## ٦. متى أعيد النسخ؟

عند الضغط على «إصدار جديد» في البوابة (طلاب جدد أو دروس جديدة): انسخ `lab.html` الجديد
فوق القديم في كل جهاز. رموز الحصص بعد الإصدار الجديد لا تعمل على الملف القديم.
