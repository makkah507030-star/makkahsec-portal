# دليلا بوابة مكة الثانوية الرقمية

- `الدليل-التنظيمي.pdf`: غاية البوابة ونطاقها، وفئات المستخدمين، والأدوار الإدارية ومسؤولياتها، واللجان والفرق،
  وخريطة الأقسام، والصلاحيات، ومسارات العمل والاعتماد، والبيانات والخصوصية، والدعم الفني، وإدارة الإصدارات،
  وملحق التعديلات بعد الإصدار الأول، والاعتماد.
- `الدليل-الإجرائي.pdf`: إجراءات البوابة كلها بخطواتها، مجموعة بفئاتها، لكل إجراء المسؤول والمسار والخطوات
  والملاحظة، وملحق الإجراءات المضافة بعد الإصدار الأول، والاعتماد.

بهوية التقارير الرسمية (`src/components/report`) كما في الاستوديو، بصفحات A4.

## المصادر (لا يُكتب المحتوى مرتين)
- الإجراءات: `PROCS` في `src/pages/Help.jsx` («دليل الاستخدام» داخل البوابة). الإجراء المضاف بعد الإصدار الأول عليه `after: true`.
- الأقسام والمجموعات: `SECTIONS` و`TEACHER_SECTIONS` و`ADMIN_GROUPS` و`TEACHER_GROUPS` و`BASIC_GROUPS` في `src/components/Layout.jsx`.
- الأدوار والصلاحيات: `ADMIN_ROLE_LABEL` و`ASSIGNABLE_ROLES` و`PERMISSIONS` في `src/lib/session.jsx`.
- نص الدليل التنظيمي (المهام، واللجان، والمسارات، والحوكمة): `harness/org.jsx`. ملحق التعديلات: `harness/changes.js`.

## إعادة البناء
بعد أي تعديل في إجراء أو قسم أو دور، أو دفعة جديدة (أضف سطرها في `harness/changes.js` وحدّث تاريخ الإصدار في `harness/main.jsx`):

    node docs/portal-guide/build.mjs                  # النسخة الملوّنة
    node docs/portal-guide/build.mjs --theme=official # النسخة الرسمية الموفّرة للحبر

يقسّم `harness/Paged.jsx` المحتوى على الصفحات بالقياس، وينبّه البناء إن قُصّ محتوى صفحة.
الملفات هنا لا تُنشر مع الموقع (`docs/` مستثناة من النشر).
