# منشور سجل التطوير المهني للمعلمين ورؤساء الأقسام

الصورة العريضة (لواتساب): `pd-guide-wide.png` (١٦٠٠ × ٩٠٠).

## النص المرافق

سجل التطوير المهني في بوابة مكة الثانوية الرقمية: وثّق مرة واحدة، ويصل شاهدك تلقائيًا

ثمانية نماذج لعنصر «التفاعل مع المجتمع المهني» بهوية البوابة، تُطبع جاهزة وتُضاف إلى «شواهد الأداء الوظيفي» بعد اعتمادها:

- 2-1 تنفيذ برنامج تدريبي: المدرّب يوثّق، والحاضرون يوقّعون (ويُحتسب للحاضرين 2-2).
- 2-2 حضور برنامج تدريبي: تقرير ذاتي وترفق الشهادة.
- 2-3 و2-4 الزيارات التبادلية: الزائر يقيّم، والمستضيف من القسم نفسه يوقّع بتعقيبه.
- 2-5 حضور مؤتمر: تقرير ذاتي وترفق الشهادة.
- 2-6 مجتمع التعلم المهني: رئيس القسم يصدره، والحاضرون يوقّعون.
- 2-7 درس تطبيقي أو حلقة تنشيطية: المنفّذ يوثّق، والحاضرون يوقّعون (ويُحتسب للحاضرين 2-2).
- 2-8 إنتاج معرفي أو تجربة أو وسيلة أو تطوير مناهج أو تطوع: تقرير ذاتي وترفق الشاهد.
- ملف التطوير المهني للقسم: لرئيس القسم، بغلاف وإحصائيات ونواقص القسم كله.

الخطوات:
١. أنشئ النموذج من «التطوير المهني».
٢. عبّئه بالبطاقات الجاهزة.
٣. يوقّع الحاضرون أو المستضيف.
٤. يعتمده وكيل الشؤون التعليمية.
٥. يُضاف تلقائيًا إلى سجل التطوير المهني في شواهدك.
