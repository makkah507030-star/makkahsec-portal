# تفعيل المساعد الذكي (Claude) في البوابة

مهمته الوحيدة: **توليد أسئلة الاختبارات** من نص الدرس أو صفحاته، في محرّر الاختبار.
يعمل عبر دالة خادم في Supabase (`supabase/functions/ai-assistant`)، والمفتاح سرّ فيها لا يصل إلى المتصفح.

## 1) حساب Anthropic والمفتاح (مرة واحدة)

1. ادخل **console.anthropic.com** وأنشئ حسابًا للمدرسة.
2. **Plans & Billing** ← اشحن رصيدًا مسبقًا (مثلًا 20$ للتجربة).
3. **Limits** ← ضع **Spend limit** شهريًا (مثلًا 50$)، فلا تتجاوز الفاتورة هذا المبلغ مهما حدث.
4. **API Keys** ← **Create Key** ← سمّه `makkahsec-portal` ← انسخ المفتاح (يبدأ بـ `sk-ant-`).
   - **لا ترسله في المحادثة ولا في واتساب.** يُلصق في الخطوة التالية مباشرة.

## 2) المفتاح في Supabase

1. Supabase ← مشروع البوابة ← **Edge Functions** ← **Secrets** (أو Project Settings ← Edge Functions).
2. **Add new secret**:
   - Name: `ANTHROPIC_API_KEY`
   - Value: المفتاح المنسوخ
3. اختياري: لتغيير النموذج أضف سرًّا باسم `AI_MODEL` بقيمة `claude-sonnet-5-5` أو `claude-haiku-5-5`. بدونه يُستعمل `claude-opus-5-5` (الأقوى).

## 3) ملف SQL

شغّل `supabase/ai_assistant_1.sql` في **SQL Editor**: سجل الاستخدام، والحصة الشهرية (10 طلبات لكل معلم)، وتقرير الدعم الفني.
ويعدّل الدعم الفني الحصة من صفحة **«تقرير المساعد الذكي»**.

## 4) نشر الدالة

1. Supabase ← **Edge Functions** ← **Deploy a new function** ← **Via Editor**.
2. الاسم بالضبط: `ai-assistant`.
3. احذف الكود الافتراضي، والصق محتوى الملف `supabase/functions/ai-assistant/index.ts` كاملًا.
4. **Deploy**. وإن ظهر خيار التحقق من JWT (Verify JWT) فاتركه مفعّلًا كما هو افتراضيًا.

## 5) التجربة

1. ادخل بحساب معلم ← اختباراتي ← افتح اختبارًا (مسودة) ← تحت «إضافة سؤال» اضغط **✨ توليد أسئلة بالمساعد الذكي**.
2. الصق فقرة من درس، واختر 3 أسئلة، واضغط «ولّد». تظهر الأسئلة خلال دقيقة تقريبًا.

## المتابعة والتكلفة

- كل طلب يُسجَّل في جدول `ai_usage`: من طلب، ومتى، والنموذج، والوحدات، والتكلفة التقريبية بالدولار.
- **التكلفة للدعم الفني وحده:** القائمة ← الدعم الفني ← **«تقرير المساعد الذكي»**: لكل معلم الطلبات والأسئلة والتكلفة، بالشهر، مع تعديل الحد الشهري.
  المعلم يرى عدد طلباته من حدّه فقط، بلا تكلفة.
- الفاتورة الدقيقة في لوحة Anthropic ← **Usage**.

## الأمان والخصوصية

- للمعلم صاحب الاختبار وحده، ولا يقبل إلا مهمة «توليد الأسئلة» (لا محادثة مفتوحة).
- يُرسل نص الدرس أو صفحاته فقط؛ لا أسماء طلاب ولا درجات.
- الأسئلة مسودة يراجعها المعلم قبل إضافتها، والشرح 💡 لا يظهر للطلاب.
