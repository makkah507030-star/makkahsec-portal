# بوابة مكة الثانوية الرقمية — الإصدار الأول (v1.0)

**التاريخ:** 1448هـ · أكتوبر 2026م
**الموقع:** makkahsec.com
**الوسم في المستودع:** `v1.0` على `main` بعد دمج الدفعة الأخيرة (#268)

الإصدار الأول يجمع خدمات المدرسة كلها في منصة واحدة للطالب وولي الأمر والمعلم والإدارة، بالهوية الرسمية الفاتحة افتراضيًا ومعها الشكل الكلاسيكي اختيارًا. بعد هذا الإصدار تُغلق الإضافات، ويُضم أي تطوير جديد إلى دفعة الإصدار التالي.

## الخدمات في الإصدار الأول

### الطالب وولي الأمر
- الرئيسية: الحضور ومؤشر السلوك والشارات، ومنها شارة الرتبة الكشفية.
- سجل الغياب والتأخر، وتقديم الأعذار ببطاقات الأعذار المقبولة رسميًا وإثباتها.
- إشعار الفترة والنتائج والشهادات.
- الاختبارات الإلكترونية ونتائجها.
- مركز التدريب على القدرات.
- نتائج قياس: يُدخلها الطالب اختياريًا، ويطّلع عليها ولي الأمر.
- الجدول الأسبوعي وجداول الاختبارات، ونماذجي وشهاداتي، وفرص المشاركة والترشيح، والتعاميم والإشعارات.

### المعلم
- التحضير اليومي وحصص الانتظار، والسجلات وسجل المتابعة الإلكتروني.
- تقرير غياب المادة، والإحالة، والإبلاغ عن طالب منقطع.
- الاختبارات الإلكترونية والتصحيح الآلي، وبنك الأسئلة المشترك، وتحليل النتائج.
- الأنشطة والألعاب ودوري المادة.
- ملاحظات التحصيل والخطط العلاجية.
- النماذج والشهادات والتوقيع، وشواهد الأداء الوظيفي وخطط التطوير، وملف المعلم الرقمي والتطوير المهني.

### شؤون الطلاب والتوجيه
- كشوف الطلاب، وملف الطالب الشامل، ومنه التواصل مع ولي الأمر عبر البوابة وتقييم متابعته.
- قبول طالب، وتعريف طالب منتظم، والاستئذان، والمنقطعون.
- أعذار الغياب ببطاقات رد جاهزة، ونماذج السلوك والمواظبة.
- الإحالة، والإنذار المبكر، والحالات الإرشادية، وملاحظات الطلاب الصحية.
- طلبات التواصل مع الوكيل، وتقارير شؤون الطلاب.

### الشؤون التعليمية والتحصيل الدراسي
- الجدول العام وجداول المعلمين والطلاب، واستيراد الجدول الذكي، وحصص الانتظار.
- متابعة رصد الدرجات ودورات الاختبار، وبنك الأسئلة وبنك الأنشطة، والمناوبة والإشراف، ورؤساء الأقسام.
- **قسم التحصيل الدراسي:**
  - **مركز تحليل النتائج:** الفترة الأولى والثانية والاختبار النهائي، والملاحظات الآلية.
  - **نماذج ملاحظة التحصيل والخطط العلاجية:** يرسلها الموجه، ويرد المعلم، ويعتمدها الوكيل.
  - **لجنة التحصيل ومحاضرها.**
  - **اختبارات قياس:** القدرات والتحصيلي وSTEP.

### النماذج والأداء الوظيفي
- إصدار النماذج والشهادات والاعتماد.
- تقييم الأداء الوظيفي وشواهده، وخطط التطوير وحلقة التحسين.
- مجتمع التعلم المهني والزيارات التبادلية، ودليل اعتماد أنشطة التطوير المهني.
- ملفات المعلمين الرقمية، وميثاق أخلاقيات المهنة.

### التواصل والفعاليات
- الإشعارات والتعاميم، والأخبار والمقالات والأدلة.
- الأحداث والمناسبات وشهاداتها، ومنها الحدث العام لجميع الصفوف أو لصف معين.
- استوديو البوابة للتصاميم، ومنه بطاقة الكشاف.
- الفريق الكشفي، وشاشة المتابعة، والتقرير الشهري.

### الإعدادات والدعم الفني
- الحسابات والأدوار والصلاحيات، والتقويم والإجازات، والتوقيت الزمني ومعه رمضان.
- الاستيراد وتعديل السجلات، ومركز الدعم والمساندة.
- سجل الدخول والعمليات، ومؤشرات الاستخدام.
- الهوية الرسمية والكلاسيكية.
