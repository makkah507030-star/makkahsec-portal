# منشور الإعلان: «الحصة النموذجية» في استوديو البوابة

الصورة العريضة (لواتساب): `model-lesson-studio.png` (١٦٠٠ × ٩٠٠)، تُعاد من `studio.html`.
منشور قصير يحيل المعلم إلى الاستوديو بدل إرفاق الملف، ولا يشرح دليل المعلم.

## النص المرافق

جديد في استوديو البوابة: الحصة النموذجية بثمانية ألوان

قالب PowerPoint تفاعلي لحصة 50 دقيقة بإجراءات التدريس الفعّال، مطابق لبنود الملاحظة الصفية في منصة هيئة تقويم التعليم والتدريب، ويصلح لكل المواد.

★ سبع مراحل بزمن محدد: التهيئة، والأهداف، والشرح بالمثال، والتعلم التعاوني، والمهام المتمايزة، والتقويم الختامي، والخلاصة والواجب.
★ تفاعلي بلا برامج إضافية: مؤقت لكل مرحلة، وكشف الإجابة بصوت، و«لوحة التميز» للمجموعات.
★ ثمانية ألوان: الأخضر، والأزرق، والأزرق المخضر، والبنفسجي، والكحلي، والأحمر، والذهبي، والرمادي؛ وهي ألوان ملف المعلم الرقمي نفسها.

للتنزيل:
البوابة ← استوديو البوابة ← المعلمين ← «حصة نموذجية» ← اختر لون العرض ← تنزيل الملف
